# NeetCode — Data Structures & Algorithms Practice

A collection of my **Python solutions and submissions** to coding interview problems on [NeetCode](https://neetcode.io/).

I use these exercises to practice problem-solving, data structures, algorithms, and reasoning about **time and space complexity**.

## Topics

The repository includes problems involving:

- **Arrays & Hashing** — hash maps, sets, duplicates, anagrams
- **Two Pointers** — palindrome validation, two-sum on sorted arrays, container with most water
- **Sliding Window** — longest substring without repeated characters
- **Binary Search** — searching sorted data
- **Stacks** — validating parentheses
- **Linked Lists** — reversing a singly linked list

## Repository Structure
